# WanderLux Travel Agency — ICT502 Assessment 2

This is a **starter project scaffold**, not the completed assignment website.

## Open in VS Code
1. Extract `WanderLux_Starter_Project.zip`.
2. In VS Code, select **File > Open Folder**.
3. Select the extracted `WanderLux` folder.
4. Open `index.html` and follow the step-by-step code instructions in our chat.

## Files
- Six HTML pages in the project root
- `css/style.css` for shared styling
- `js/main.js`, `carousel.js`, `calculator.js`, `forms.js` for JavaScript
- `images/` for destination photographs

## Important
- Current HTML is minimal placeholder content; CSS and JS are not yet implemented.
- Email delivery requires a configured external form service and testing.
- A live URL will only exist after you deploy the finished site.
